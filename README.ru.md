# ICHGRAM - Фронтенд (React / Vite)

Пользовательский интерфейс клона социальной сети. Проект отличается современным дизайном с использованием глобального управления состоянием, адаптивной версткой и интеграцией ИИ.

## 🚀 Быстрый старт

**1. Установка зависимостей**  
Убедись, что у тебя установлен Node.js (рекомендуется v18+).
```bash
npm install

2. Настройка окружения
В проекте настроен автоматический фолбэк на локальный бэкенд (http://localhost:3333/api), поэтому для базового запуска создавать .env не обязательно.

Однако для деплоя или кастомной настройки создайте файл .env в корне проекта и укажите:
VITE_API_URL=http://localhost:3333/api

3. Запуск проекта
npm run dev
Проект будет доступен по адресу: http://localhost:5173

🛠 Стек технологий
Сборщик: Vite (молниеносный HMR)

Ядро: React 18 (Hooks)

Стилизация: Tailwind CSS v4 (с переопределением типографики на глобальный шрифт Roboto)

Маршрутизация: React Router DOM v6

Управление состоянием: Zustand (легковесная архитектура для глобальных уведомлений)

Иконки: Lucide React

API Клиент: Axios с настроенными интерцепторами для автоматической передачи JWT токена

Интеграция ИИ: Groq API (модель llama-3.1-8b-instant) через бэкенд

Хранение медиа: Cloudinary (оптимизированный конвейер изображений)

🏗 Архитектура и реализованные функции
Глобальная лента (Home): Рендеринг постов из базы данных с плейсхолдерами для лайков. Адаптивный дизайн (Mobile-first).

AI Бизнес-ассистент: Встроенный чат на базе Groq (llama-3.1-8b-instant), выполняющий роль SMM-эксперта и копирайтера.

Оптимизированная загрузка медиа: Формы, разработанные для эффективной загрузки изображений, которые затем обрабатываются и сохраняются в Cloudinary через бэкенд.

Поиск (Search Drawer): Реализован с использованием паттерна Debounce (500мс), чтобы избежать спама запросами на бэкенд при каждом нажатии клавиши.

Уведомления (Zustand Store): Глобальное управление состоянием. Индикатор непрочитанных сообщений (красная точка) отключается при открытии панели, используя оптимистичное обновление UI.

Личные сообщения (Direct Messages): Замоканы для MVP. В целях экономии ресурсов и подготовки к Serverless-развертыванию, чаты в реальном времени на WebSocket были заморожены (реализован UI-блок с объяснением).

⚠️ Важное замечание для проверяющего
Для корректной работы приложения сначала запустите бэкенд и выполните сидирование базы данных (node seed.js), как описано в README.md бэкенд-репозитория. Без этого интерфейс ленты будет пустым, так как база данных изначально чиста.
